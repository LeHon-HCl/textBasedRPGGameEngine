# study —— 仅用于学习的目录（请勿改动）

> **⚠️ 给本项目其他开发者（人类或 AI 代理）的声明：**

**本目录（`study/`）是新人学习用的私人空间，不属于产品代码、不属于文档体系、不参与任何工程门禁。请在开发时完全忽略它：不要 review、不要修改、不要引用其中的内容，也不要在评审/PR 中把它当作改动的一部分。**

具体约定：

- **不参与门禁**：`study/` 不被 `scripts/validate-docs.mjs` 扫描，不进入 ESLint / Prettier / Vitest / 覆盖率统计 / CI 的任何一道门禁；它的内容不会导致也无需通过任何校验。
- **不是文档体系**：它不在 `docs/` 之下，不属于 develop.md 定义的「文档层级」（proposal / detail-design / architecture / develop / tasks / progress / reviews / retros）。**禁止**将其内容作为设计依据、验收依据或代码注释的来源引用。
- **不被维护**：项目文档同步（约束 1）、文档修订审查（约束 2）、反思报告（约束 3）等约定**均不适用于本目录**。它不保证反映项目最新状态，只反映学习者的个人进度。
- **提交策略**：学习进度更新可随学习过程随时 commit（建议单独 commit，前缀 `docs(study)`），不影响主分支的 PR 规范判断。

## 目录结构

| 文件 | 用途 |
|---|---|
| `学习进度.md` | **总学习进度**：剩余文件统计、学习路线、最新学习任务（随项目进展更新） |
| `文件清单.md` | 全部 750 个需学习文件的勾选清单（`- [ ]` 未读 / `- [x]` 已读） |
| `笔记/*.md`（后续逐步新增） | 按模块的学习笔记，记录理解、疑问与总结 |

## 学习者

本项目的前端新人学习者（当前为个人学习，随学习者需要可扩展）。

## 维护说明

- 本 README 的「忽略声明」是目录存在的核心契约，**不要删除或弱化**。
- 新增学习笔记放在 `笔记/` 子目录，命名与模块对应（如 `笔记/03-表达式求值器.md`）。
