## 使用约定

1. **子任务粒度 = 一次 commit**：每完成一个 `- [ ]` 子任务，勾选并提交对应 commit（AGENTS.md 规则全程适用：改动必须带测试且测试全绿后才交付）。
2. **按依赖顺序推进**：模块表中的「前置」未完成不得开工；同一模块内子任务按分组顺序执行。
3. **模块完成标志**：该模块 .md 的子任务全部勾选 + 「完成定义」达成 → 回到本页勾选对应模块，并运行 `node scripts/validate-docs.mjs` 后提交。
4. **里程碑门禁**：proposal §7 的发布门禁（全量测试 + E2E 冒烟 + 旧档回归）在每里程碑收尾时执行。
