# Demo 人工检查路径（L3）—— 最短全覆盖清单

> 用途：**人工目视验收**（机器检查的补充）。L2 三层自动化检查已覆盖「选项可达且有效果 /
> 事件可触发 / 主线闭环」的逻辑面；本清单只查**机器判不了的东西**——文案可读性、
> 打字机手感、布局换行、动画观感、交互反馈。
>
> 执行方式：`pnpm dev:player` → 浏览器打开 → 按清单逐步点击（约 25 步，10 分钟）。
> 每步的「预期」是**看得见的现象**；不符合即记为缺陷（附截图与步骤号）。

## 准备

- 启动：`pnpm dev:player`（默认 <http://localhost:5173>）
- 首次进入会有**内容警告向导**（勾选标签后进入）
- 建议窗口宽度：先按默认（宽屏），第 8 步换窄屏（< 900px）复验布局

---

## 第 1 步：首启向导与主界面

| 操作 | 预期 |
|---|---|
| 阅读内容警告 → 勾选 `general` → 确认 | 进入游戏；顶部有「第 1 天 · 上午」时钟 |
| 观察主界面 | 左侧叙事区 + 右侧三面板（状态 / 地图 / 任务） |

**检查点**：向导文案是否通顺；进入后是否有报错卡片（红框）；三面板标题是否齐全
（此前有「任务」标题缺失的缺陷）。

## 第 2 步：阅读体验（打字机 / 跳过 / 自动）

| 操作 | 预期 |
|---|---|
| 点「继续」推进一段 | 文字逐字出现（打字机）；再次点击立即全显 |
| 点工具条「跳过：关」 | 变为「跳过：开」；后续段落**直接全显** |
| 点「自动：关」→ 观察 | 变为「自动：播放中」，段落自动推进 |
| 推进到出现选项 | 自动播放**暂停**（不再自动推进）——这是设计的安全边界 |

**检查点**：打字机是否流畅（不卡顿、不重排）；跳过开关是否即时生效；自动播放
在选项处确实停下。

## 第 3 步：快捷键

| 操作 | 预期 |
|---|---|
| 按 `1` / `2` | 选择第 1 / 第 2 个选项 |
| 按 `Space` | 推进一段 |
| 按 `H` | 历史面板开合 |
| 按 `R` | 回退一步（数值回退，画面回入口） |

**检查点**：按键是否生效；在设置面板输入框里打字时**不应**触发快捷键（焦点保护）。

## 第 4 步：历史回看与回退

| 操作 | 预期 |
|---|---|
| 点「历史」按钮（或按 `H`） | 历史面板显示已读文本，按「场景 + 日期」分组 |
| 点某组的「回退 N 步到这里」 | 状态回退到该处；画面回入口场景（设计口径：只还原状态） |
| 点「回退一步」按钮 | 同上，退一步 |

**检查点**：历史文本是否完整可读（不是原始文本键）；分组标题是否合理。

## 第 5 步：集市与商店（**本次新接通**）

| 操作 | 预期 |
|---|---|
| 从石板路口点「去集市」 | 进入集市，文本变化 |
| 点「逛杂货铺」 | **商店面板出现**：商品列表（包子 / 卫兵外套）、价格、库存、钱袋 |
| 点包子旁的「买」 | 钱袋减少、背包增加、库存减 1 |
| 连点「买」直到库存 0 | 显示「售罄」且按钮禁用 |
| 点「卖」 | 钱袋增加、背包减少 |
| 点「离开商店」 | 面板关闭，回到叙事 |

**检查点**：**这一步此前是「点了没反应」**——若仍无反应，说明接线回归了；
价格文案是否合理（声望高时应打九折）。

## 第 6 步：任务链之一（墙中徽记）

| 操作 | 预期 |
|---|---|
| 集市点「凑近听摊贩的低语」 | 提示已获得传闻；自动跳转镇口 |
| 镇口点「与老卫兵搭话」 | 提示已结识 |
| 镇口点「辨认徽记」 | 提示已接取任务；任务日志出现「墙中徽记」 |
| 等待/推进到傍晚或夜晚 | 触发「墙中低语」事件：选「拓下徽记」 |
| 回镇口点「提交拓片」 | **获得 20 银 + 好感**；任务日志显示已完成 |

**检查点**：任务日志条目文案（不是原始键）；事件是否自动弹出并能在其中选择；
提交后奖励是否有 Toast。

## 第 7 步：检定与战斗（**本次新接通**）

| 操作 | 预期 |
|---|---|
| 出镇门 → 渡口 → 河堤（需洞察≥3）→ 上山 | 逐级解锁，地图新增区域 |
| 山道口点「辨认碎石上的凿痕」 | **判定结果出现**：骰值 + 等级（大成功/困难成功/…）+ 成败；成功后解锁采石场 |
| 采石场点「打岩鼠」 | **战斗面板出现**：两只岩鼠 + 我方血条 + 战斗日志 + 行动按钮 |
| 点「strike」（或技能名） | 敌人掉血；日志新增条目 |
| 点「防御」 | 显示「防御中」标记 |
| 反复攻击直到胜利 | 显示「胜利」→ 面板关闭 → 提示已清剿（10 银入账） |

**检查点**：**这两步此前都是「点了没反应」**；骰值是否显示；战斗日志是否可读
（不是原始键）；血条是否随伤害变化。

## 第 8 步：窄屏布局复验

| 操作 | 预期 |
|---|---|
| 窗口缩到 < 900px | 右侧栏折叠为底部 Tab（状态 / 地图 / 任务） |
| 切换三个 Tab | 各面板正常显示，标题齐全 |

**检查点**：是否有横向滚动条；文字是否溢出。

## 第 9 步：成就与设置

| 操作 | 预期 |
|---|---|
| 点工具条「成就」 | 成就图鉴：分组、进度条、收集率；未解锁的隐藏成就显示「???」 |
| 打开设置 | 语言切换（zh/en）、文本速度、字号行距、内容标签、快捷键说明、三版本号 |
| 切到 English | 界面与叙事文案变英文 |

**检查点**：成就名是否为译文（不是键）；隐藏成就是否**不泄露名称**；
en 切换后是否有残留中文。

## 第 10 步：存读档与刷新

| 操作 | 预期 |
|---|---|
| 存档 → 刷新页面 → 继续 | 状态与位置恢复 |
| 导出存档 → 观察 | 生成 JSON（可下载/复制） |

**检查点**：读档后是否回到正确场景；数值是否一致。

## 已知问题（检查时请留意，不必重复报告）

| # | 现象 | 状态 |
|---|---|---|
| 1 | **回退后画面回入口场景**（而非回退到当时的场景位置） | 设计口径（§6.3「回滚只还原状态，叙事位置须重开会话」）；精确还原登记为 M4 打磨项 |
| 2 | **`requires` 未满足时「接下勘察委托」仍可见** | L2-C 检查抓出的待查缺陷（已登记，待 M2 收尾处理） |
| 3 | 周目切换在浏览器里**无入口** | `ending → loop_transition` 的宿主消费未接线（与商店/战斗同类，已登记）；引擎侧全链已由 L2-C-3 验证 |
| 4 | 调试面板不可见 | 需 manifest 声明 `debug: true`（demo 未开，属预期） |
| 5 | 回退深度上限 5 步 | 性能护栏（`PERF_GUARD.checkpointStackDepth = 5`）；「回滚 5 步」需 6 次选择 |
